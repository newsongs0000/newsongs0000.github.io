# Background pictures

The `ChapterN-bg.jpg` files are the movements' Image backgrounds (`background` in `work.js`; see **Background** in
the README). Each is a public-domain or CC0 picture from Wikimedia Commons, cropped to 3:2 around its subject
and saved 1024 px wide (the backgrounds are shown blurred). The source page has the full-size original and its license details.
`../MessiahChinese/work.js` uses the same pictures for the same movements.
