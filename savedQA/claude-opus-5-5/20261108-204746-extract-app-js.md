# Session 2026-11-08 20:47 — Move JavaScript into a separate file

## Ask

Carve Javascript code out index.html into a separate .js file

## Answer

- The single inline `<script>` block at the end of `<body>` (about 1060 lines: APP_DATA, player logic, lyrics timing,
  keyboard shortcuts, init) moved to a new file **`app.js`** next to `index.html`. It was moved as-is: `diff` against
  the committed block shows no differences, and `node --check app.js` passes.
- `index.html` now has `<script src="app.js"></script>` in the same place, at the end of `<body>`, so the script still
  runs after the DOM is built and nothing about load order changes. `index.html` is down to 102 lines (HTML only).
- `app.js` is a classic script, not a module, so its top-level names (`APP_DATA`, `state`, `audio`, …) are still
  global. It also still works from `file://`, which ES modules would not.
- The `ChapterN.timing.js` lyric files still load: their paths are relative to the page, not to `app.js`.

Verified in headless Chrome from `file://`: no console errors; Chapter 1's 55 lyric lines load from
`Chapter1.timing.js`; the one-line header, Maximize and Esc still work.

The app is now `index.html` + `common.css` + `app.js` + `assets/`. All three files must be copied or deployed together.
