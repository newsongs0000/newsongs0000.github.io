# Update README.md

## Ask

The current README.md was a draft, does not cover all functionalities and flows; Update it

## Answer

Rewrote `README.md` from the current code (`index.html`, `app.js`, `common.css`) and data files (`artist.js`,
`work.js`, `*.timing.js`). It now covers:

- Running the app: from `file://` (the usual way), or over HTTP with a server that supports Range requests
  (`python3 -m http.server` does not, so seeking fails).
- Screen layout: a diagram, then each area (tree, LYRICS TIMING panel, top controls, lyrics, picture overlay, bottom
  controls, info pane).
- Playing music: selecting a movement, auto-advance at the end, and Prev/Next following the data order rather than
  the alphabetical tree order.
- Lyrics highlight modes: Auto and Manual compared, how Auto picks the current line (times, then even spacing), and
  Manual-mode details.
- Maximized lyrics, and a table of keyboard shortcuts in each mode.
- Configuration: the URL parameters (`above-color`, `above-bg`, `below-color`, `below-bg`, `highlight-mode`), plus a
  note that the current-line colors and the number of lines above and below can only be changed in `common.css` and
  `app.js`.
- Flow: timing the lyrics (Record, Check, Save/Export, Clear and commit, Load).
- Flow: modifying lyrics, including clicking Clear on a browser recording because it matches times to lines by
  position.
- Flow: adding an artist, work or movement, with annotated `artist.js`, `work.js` and `.timing.js` templates and the
  warning that the ids must match.
- Data files reference, the order in which times take precedence, project structure, browser notes (File System
  Access API, localStorage per browser and per origin) and the development workflow (`workItems/`).

Gaps found against CLAUDE.md, documented in the README but not changed in code:

- The current-line text and background colors have no URL parameter.
- The number of lines above and below the current line is fixed at 4, with no URL parameter.
