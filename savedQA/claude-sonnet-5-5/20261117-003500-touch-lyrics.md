# Touch on the lyrics (mobile)

- Session: 2026-11-17 00:35
- Model: claude-sonnet-5-5

## Ask

> Enable touching on the lyrics on mobile devices

## Response

In Manual mode, which has no arrow keys on a touch screen, **swiping** on the lyrics now steps the highlight: up or
left = next line (↓ →), down or right = previous (↑ ←), for a swipe of at least 40 px. Tapping a line still
highlights it and seeks to it. In Manual mode the lyrics no longer scroll by touch (`touch-action: none`); the
highlighted line is kept centered anyway. Auto mode is unchanged, and a swipe starting on the column divider is
ignored, so the divider can still be dragged.

| File | Change |
|---|---|
| `app.js` | New SWIPE section; `setHighlightMode` sets `data-mode` on `#lyrics-container` |
| `common.css` | `#lyrics-container[data-mode="manual"] { touch-action: none; }` |
| `index.html` | Manual hint mentions the swipe |
| `README.md` | Swipe paragraph in Lyrics highlight modes |

### Verification

Headless Chrome with touch emulation (800 px, mobile), Chinese Requiem chapter 1: swipe up twice → line 1 then 2
(index 0, 1); swipe down → back; swipe left / right → next / back; a tap on a line selects it. Not tested on a real
phone, Firefox or Safari.
